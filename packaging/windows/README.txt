AURORA/86 for Windows x64

SETUP
Run AURORA86-Setup-x64.exe. It installs for your Windows account without
administrator rights. C++ compilers, Qt and separate development tools are
not needed. The necessary Qt and Microsoft C++ runtime DLLs are included.

PORTABLE ZIP
Extract the complete AURORA86-Windows-x86_64.zip archive, open its folder,
and run aurora86.exe. Keep the DLLs, plugins, resources and translations
beside the executable. Moving only aurora86.exe will not work.

Requires Windows 10/11 x64. F11 toggles fullscreen.
The operating system interface is English. README.pt-BR.md contains
Portuguese instructions. Import images through Settings and use the
virtual disk from Terminal. Host Windows commands are not executed.

The simulator saves its virtual disk in your account's application-data
folder, outside the installation. Uninstalling AURORA/86 keeps that data.
An alternative save directory can be selected with --state-dir PATH.

This is an unsigned community build. Source and dependency information:
https://github.com/fis4med2/Aurora86
